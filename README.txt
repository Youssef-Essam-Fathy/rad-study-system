STUDY SYSTEM

Open index.html in a modern browser. The subject apps work as standalone HTML files and make no network requests.

Subjects detected from file contents
- Angiography: basic technique, cerebral, coronary and renal angiography presentations.
- CT Physics: CT introduction, X-ray production, detector conversion, penetration and photon range.

Each subject folder contains an HTML app, source visuals, and copies of its original source files. Originals on F: were not edited or moved. Progress is stored in browser local storage and can be exported/imported as JSON.

Flashcards review mode
- Every lesson ships curated Egyptian-Arabic review cards plus one card per lesson multiple-choice question.
- Cards you mark as known are tracked locally in a separate storage key; the "Not known yet" deck shows only the rest.
- Card progress stays in the browser and is not part of the lesson progress JSON export.

Midterm bank and focus mode
- The Angiography app embeds the real midterm question bank (240 multiple-choice and true/false items from the user's PDF) distributed across the 13 lessons.
- Each lesson has a collapsed "Midterm question bank" section intended for self-testing after studying the lesson.
- Focus mode lets the student pick a duration (10-60 minutes) and study one lesson behind a full-screen timer; the timer persists across page reloads and cannot be dismissed until it finishes.

Accuracy and grading limits
- Lessons are presented in Arabic; every assessment question, option, answer explanation, and feedback label is in English.
- All assessment items are multiple-choice questions and are objectively auto-graded. There is no essay or semantic-answer grading.
- Source visuals are extracted from the supplied PPT/PPTX/PDF files and shown with their available source location. Legacy PPT image extraction cannot reliably preserve slide numbers, so these figures use “Embedded visual N”.
- Legacy .ppt text extraction does not preserve slide numbers; “Text block N” is a text extraction location, not a slide number.
- Some diagrams, image-only text, vector artwork, or legacy-PPT graphics may not be available as web images.
- External AI/API integration is optional and unconfigured.
- Medical procedure details and parameters remain subject to the source lecture, instructor, and institutional protocols.
